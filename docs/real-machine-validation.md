# 真机验证清单

用于在真实硬件上验收 `plugin-todoocard-general` + `plugin-todoocard-general-core`。单元测试不能替代 BLE 实测。

## 0. 准备

```bash
npm install
npm test
npm run build
```

安装 `package.zip` 到思源，或在开发目录执行 `npm run make-link`。确认顶栏出现「土豆片通用 · TodooCard General」。

## 1. 环境与核心安装

1. 打开面板，环境检查应显示 Python 版本、当前平台、核心依赖三项。
2. 缺少 Python 时点「获取 Python」，安装后确认插件能自动复查。
3. 点「下载核心」，日志应依次出现下载、SHA-256 校验、解压、创建 venv、安装依赖、模块自检。
4. 状态变为「就绪」，设置页能看到核心目录、venv Python 路径和安装时间。
5. 断网后重新下载，应失败且保留旧核心，原核心仍可运行。

## 2. 扫描与设备管理

1. 唤醒卡片，点「扫描设备」，30 秒内应列出兼容设备（manufacturer `0x5053`、screen `0x134C`）。
2. 关闭「仅兼容」应能看到更多 BLE 设备；搜索、排序、配对状态筛选正常。
3. 给设备写备注名，重启思源后备注仍在。
4. macOS 记录的是 UUID，Windows 记录的是 MAC；同一台卡片在各自平台上都能被识别。

## 3. 配对与探测

1. 长按卡片按钮进入配对窗口，点「配对」并按系统提示确认。
2. 配对成功后「探测」应读到电量。
3. 未配对时探测应返回明确错误，面板不能显示成功。
4. 配对窗口关闭后重试，应提示重新进入配对模式。

## 4. 图片转换与预览

1. 选择 JPG / PNG，拖入一张图片，2:3 取景框可拖动缩放。
2. 点「生成预览」，应显示 528×792 六色预览、v157+ payload 大小和 legacy payload 大小。
3. 测试 HEIC / TIFF / WebP：macOS 走 `sips`，Windows 走 Electron `nativeImage`；无法预览时应给出转格式提示。
4. 剪贴板截图粘贴、向右旋转 90° 正常。
5. 卡片排版三种版式都能生成，照片墙 2–6 张可排序移除，Bing 壁纸可切换。

## 5. 发送

1. 勾选一台设备，发送前核对清单，确认后发送。
2. 日志出现 `Progress:` 递增，最终出现 `Transfer completed and refresh acknowledged by 0x05/0x08`。
3. 卡片刷新为发送的图片。
4. 勾选多台设备批量发送，只有全部收到刷新确认才算成功；失败的目标单独标出。
5. 发送过程中关闭面板或重启思源，进程应被清理，不残留 venv Python 进程。

## 7. 已知边界

- Linux 核心可用，但插件暂未在 Linux 上开放。
- HEIC 预览依赖系统解码器；核心侧 HEIC 输入需要 `pillow-heif`。
- 配对和发送必须由用户显式触发，插件不会后台自动连接。
