# 配对与发送指南（macOS / Windows）

插件本身不直接操作蓝牙，扫描、配对、探测和发送都交给 `plugin-todoocard-general-core`。两个平台的协议一致，差别在系统绑定方式。

## 发送前检查

1. 卡片电量充足，放在电脑旁边。
2. 卡片已唤醒。土豆片平时不广播，扫描前需要短按/长按唤醒。
3. 系统蓝牙已打开，并允许思源使用蓝牙：
   - macOS：系统设置 → 隐私与安全性 → 蓝牙 → 勾选 SiYuan。
   - Windows：设置 → 蓝牙和其他设备，确认蓝牙开关打开。
4. 插件设置里核心状态为「就绪」。不是就绪时先完成环境检查和核心下载。

## macOS

1. 在「设备」页点 **扫描设备**，选中卡片。
2. 首次连接时点 **配对**，同时长按卡片背面按钮 5 秒（旧固件 10 秒）进入配对窗口。
3. 系统弹出蓝牙配对提示时点 **允许**。核心会读取加密的 Battery Level 作为绑定证明。
4. 配对成功后点 **探测**，能看到电量即表示加密链路正常。

如果系统里残留旧绑定：系统设置 → 蓝牙 → 找到设备 → 忽略此设备，然后重新配对。

## Windows

1. 在「设备」页点 **扫描设备**，此时设备 ID 是 MAC 地址（如 `AA:BB:CC:DD:EE:FF`）。
2. 点 **配对**，长按卡片背面按钮进入配对窗口。核心通过 `BleakClient.pair()` 建立系统绑定，可能弹出 Windows 的配对确认。
3. 配对成功后点 **探测**，读取电量验证加密链路。

如果配对反复失败：设置 → 蓝牙和其他设备 → 移除该设备，关闭再打开蓝牙，然后重新扫描配对。

## 常见错误

| 现象 | 处理 |
| --- | --- |
| 扫描列表为空 | 卡片没唤醒、距离太远，或思源没有蓝牙权限 |
| 扫描报「蓝牙已关闭」 | 打开系统蓝牙后重新扫描 |
| 配对提示窗口已关闭 | 重新长按卡片按钮进入配对窗口，再点配对 |
| 探测提示绑定不可用 | 系统绑定丢失，先移除旧设备再重新配对 |
| 发送后卡片没刷新 | 确认收到 `0x05/0x08` 刷新确认；失败时看面板日志和 `state.json` 同级的核心输出 |
| Windows 下发送超时 | 卡片可能被手机占用，断开手机后重试 |

配对和发送都是显式操作，插件不会在后台自动连接卡片。
